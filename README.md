# Flaskr – блог на Flask

Простой блог с регистрацией, аутентификацией и публикацией записей.  
Учебный проект по официальному туториалу Flask.

## Стек
- **Frontend**: HTML, CSS (шаблоны Jinja2)
- **Backend**: Python, Flask
- **DB**: SQLite

## Локальный запуск
1. Клонируйте репозиторий:  
   `git clone https://github.com/Shiniluvv/flaskr-blog.git`
2. Создайте виртуальное окружение и активируйте его.
3. Установите зависимости:  
   `pip install flask`
4. Инициализируйте базу данных:  
   `flask --app flaskr init-db`
5. Запустите сервер:  
   `flask --app flaskr run --debug`
6. Откройте `http://127.0.0.1:5000`
